Settings for the whole site, read from the properties above. This text isn't shown anywhere.

- `name`: in the header (lowercased) and every tab title.
- `tagline`: the description search engines and link previews show for the homepage.
- `role`: the line under the name.
- `places`: the grey line under that. Plain text, or a link like "[scalepad](https://…)".
- `links`: the row of links under the header, after "about". Each one a link like "[github](https://…)".
- `projects`: the order of projects in the index and on the homepage, top to bottom. Each one a link to the project's note, like "[[projects/whisk]]" (type `[[` to pick one); renaming a project updates its link. Projects left out go after the listed ones, newest first by `published`. A link to a project that doesn't exist stops the site from building, with an error naming it.
